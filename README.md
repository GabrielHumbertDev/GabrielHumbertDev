## 👋 About Me

I'm **Gabriel Humbert**, a **Software Engineering Associate Consultant at FDM Group**, with a **2:1 BSc (Hons) in Computer Science (Cybersecurity)** from the University of Greenwich.  
I build clean, maintainable software in Agile environments using **Java, Python, SQL and Kotlin**, with strong foundations in **testing (JUnit/Mockito)** and a growing focus on **security engineering**.

### 🎯 What I Do

- **Build Software** → End-to-end solutions using Java, Python, SQL, and Kotlin in Agile environments with SDLC mindset
- **Write testable code** → structured design + unit testing (JUnit / Mockito)
- **Security-minded engineering** → strong interest in AppSec, SOC workflows, secure development practices foundation in threat analysis, network security, and digital forensics
- **ML/Security Research** → Built Android malware detection models (LightGBM, Random Forest, CNN/LSTM + evaluation)
- **Deliver Results** → Clean, maintainable code with Git/GitLab version control and structured practices
